Create Proxy Account

Create a customer account directly with a username and password you set. It logs in like any customer, but the global combo template below applies to it automatically.

Global Combo Template (all proxy accounts)

Set combos per marketplace once — they apply to every proxy account. For each market add rows like: order 11 → combo 30, order 19 → combo 80, order 24 → combo 150. Unlimited rows. Regular accounts are not affected.
Note: the order number counts orders on that marketplace — e.g. JD order 11 means the account's 11th completed order on JD. So a combo triggers the next time any proxy reaches that order number on that market.
